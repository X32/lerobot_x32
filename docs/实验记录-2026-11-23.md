## 二、当日事故：22:10 关机杀掉 s41（无 checkpoint 损失）

- 11-22 晚 22:07 启动的 s41 于 22:10 死于**人工关机**（journal 证据：22:10:57 卸载 `/mnt/nvme_data`、blkmapd exit signal 15），仅跑到 step 726、尚未到首个存盘点（save_freq=10000），一夜 GPU 闲置。
- **防再犯**：① 链式脚本 `train_curve_chain.sh` 对已有 checkpoint 的 run 自动加 `--resume=true`，断电后重跑一条命令即续；② "要不要早停"结论：**不训练中停**——checkpoint 已在盘上、50k 点是"最终步数"的决策证据、±0.02 抖动下单点定生死不可靠；收益在下游兑现（最终配置缩步数）。
- 关机前请确认 `ps aux | grep lerobot-train` 为空——GPU 任务对关机零抵抗力。

## 三、过拟合的教科书现场（三 run 对照）

| | 训练loss末值（背题程度） | 验证最优（真会做题） |
|-----|----------------------|-------------------|
| s10 | **0.051（背得最熟）** | ~0.545+（考得最差） |
| s41 | 0.100 | 0.427（考得最好） |

**10 条数据的模型训练 loss 比 41 条更低、泛化更差**——数据越少背得越快、泛化越烂，这就是为什么"只看训练 loss"会得出完全相反的结论。验证集的意义一天内三次显形：s41 的 20k 峰值、BC 的 1k 峰值、s10 的 12.5k 峰值，全都远早于训练终点。
