## 二、resume 续录连环坑（本版 v0.7.1 特有，全部实测）

| # | 坑 | 正确姿势 |
|---|---|---|
| 1 | `--dataset.resume` 不存在 | 顶层参数 `--resume=true` |
| 2 | resume() 强制显式 root | `--dataset.root=<数据集目录全路径>` |
| 3 | root 指**数据集目录本身**，非缓存上级 | `/mnt/nvme_data/huggingface_cache/lerobot/zihao/so101_task1`（写上级 → 找不到 meta → 退回 Hub 下载 → 断网报 ConnectError） |
| 4 | resume 时 `num_episodes` = **本次新录条数**（源码 `recorded_episodes` 从 0 计） | 已录 30 补到 50 就填 20，不是填 50 |
| 5 | resume 路径兼容性检查需要 deepdiff，首录不触发 | `uv sync --locked --extra deepdiff-dep`（已装 8.6.2） |

一锅端脚本：`myscript/record_task1_resume.sh`（改批次只改脚本里 num_episodes 一个数）。
