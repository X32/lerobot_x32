# 遥操作与示教采集操作手册（SO-101 · 本机实测配置）

> 基于 v0.7.1 源码核实（2026-11-17）。所有命令都在 `/mnt/nvme01/workplace/lerobot` 下用 `uv run` 执行。
> 架构原理见 [`采集模块架构.md`](./采集模块架构.md)；本文只讲操作。

## 0. 环境与硬件（换机/重建环境照抄；硬件为本机实测）

```bash
uv sync --locked --extra feetech --extra test --extra viz --extra dataset --extra deepdiff-dep
```

各 extra 用途：`feetech` 电机总线 · `viz` rerun 可视化 · `dataset` HF 数据集库（lerobot-record 必需） · `test` 跑测试用 · `deepdiff-dep` **resume 续录必需**（`--resume` 路径的兼容性检查要用，首次录制不触发，所以初装容易漏，2026-11-21 实测踩过）。**漏哪个，对应命令就会报 `ImportError: 'xxx' is required but not installed`**，照报错里的提示补 extra 即可。另需系统装 ffmpeg（视频编码）。

**本机硬件清单**：

| 设备              | 参数                                        | 说明                                                |
| ----------------- | ------------------------------------------- | --------------------------------------------------- |
| 从臂 SO-101       | `/dev/ttyACM0`，id=`zihao_follower_arm` | 被控/执行端，记录的是它的动作                       |
| 主臂 SO-101       | `/dev/ttyACM1`，id=`zihao_leader_arm`   | 遥操端，人手拖着走                                  |
| 相机 front        | `/dev/video0`，id 写 `index_or_path: 0` | USB HD Camera，MJPG 640×480@30 原生支持            |
| 相机 third_person | `/dev/video2`，id 写 `index_or_path: 2` | USB Camera（第三方视角），MJPG 640×480@30 原生支持 |

**规律与坑**：

- UVC 相机每颗占两个节点：**偶数号（0/2）=采集，奇数号（1/3）=元数据**（打不开是正常的）。换相机后先跑 `uv run lerobot-find-cameras opencv` 重新确认 index。
- 双相机插在同一个 USB 控制器上；MJPG 640×480×2 带宽够用，若画面卡顿/掉帧，把一颗换到另一组 USB 口。
- 标定文件：`~/.cache/huggingface/lerobot/calibration/{robots/so_follower,teleoperators/so_leader}/<id>.json`（两臂本机均已标定；重标方法见 §1.3）。
- 串口号按插入顺序分配，**重新插拔后 ttyACM0/1 可能对调**。板上 USB 序列号不变：从臂=`5CBC431912`，主臂=`5CBC430736`。稳定路径写法：`/dev/serial/by-id/usb-1a86_USB_Single_Serial_<序列号>-if00`（`ls -l /dev/serial/by-id/` 可看当前指向）；怀疑接反时跑 `uv run python myscript/identify_arms.py` 确认（拧主臂底座看哪个口在动）。
- 本机自测脚本都在仓库根 `myscript/` 下（清单见 §5 末尾）。

## 1. 首次配置与校准（新臂必做；两臂本机均已标定过）

> 流程源码核实：主/从臂走同一套 `record_calibration`（`motors_bus.py`），全程无力矩、可徒手摆臂。

### 1.1 一次性：设置电机 ID（`lerobot-setup-motors`）

全新电机（或 ID 乱的臂）只需要做一次，逐个电机写入 ID 1-6 和波特率：

```bash
# 主臂（从臂同理，type/port/id 换成 so101_follower / /dev/ttyACM0 / zihao_follower_arm）
uv run lerobot-setup-motors \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=zihao_leader_arm


lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=zihao_follower_arm

 uv run lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=zihao_leader_arm

```

流程（按 **gripper → shoulder_pan 倒序**逐个电机）：

```
Connect the controller board to the 'gripper' motor only and press enter.
'gripper' motor id set to 6
...
```

**每次只把控制板连到提示的那一个电机**（链上其他电机全拔开），回车自动写 ID，共六次。

### 1.2 校准（`lerobot-calibrate`；或连接时无标定文件自动触发）

```bash
# 校准主臂
uv run lerobot-calibrate \
    --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=zihao_leader_arm

# 校准从臂
uv run lerobot-calibrate \
    --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=zihao_follower_arm
```

交互两步（第一步摆中位、第二步扫行程）：

1. 终端打印机械臂 ASCII 示意图（官方视频：HF docs `so101#calibration-video`）
2. **摆中位**：`Move the joints to the middle of their range of motion and press ENTER`
   → 把**全部关节摆到各自行程的中位**（接近垂直中立姿势），回车 → 记录半圈归零偏移
3. **扫行程**：`Move <各关节> sequentially through their entire ranges of motion. Press ENTER to stop`
   → 依次把**每个关节缓慢转满整个行程**（肩→肘→腕→夹爪，别甩太快），全部转完按回车
   - 例外：`wrist_roll` 不扫行程，直接按整圈编码器处理
4. 看到 `Calibration saved to <路径>` 即完成

### 1.3 校准文件管理与重标定

```
~/.cache/huggingface/lerobot/calibration/
├── robots/so_follower/zihao_follower_arm.json        ← 本机已存在
└── teleoperators/so_leader/zihao_leader_arm.json     ← 本机已存在
```

- **有文件就跳过**：`calibrate()` 开头检查 `_keep_calibration_file`，存在即直接返回。
- **重标定两种方式**：① 连接时在提示 `Press ENTER to use provided calibration file ..., or type 'c' ...` 处输入 **`c`** 回车，直接重跑标定（**不用删文件**，推荐）；② 先删标定文件再跑 `lerobot-calibrate`。
- 何时需要重标：零位漂移（主臂居中、从臂明显歪）、回放整体偏移、换过/修过电机、臂的安装方式改变。
- 判别技巧：偏移出现在单关节 → 重标该臂；两个臂对照着看（主臂摆同一姿势，从臂角度和上次不一致）→ 从臂漂了。

### 2.3 双摄像头（当前标准配置）

```bash
uv run lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=zihao_follower_arm \
    --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}, third_person: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
```

- `--display_data=true`：终端原地刷新电机数值表 + 弹 rerun 窗口（相机画面 + 关节曲线）
- 限时遥操作加 `--teleop_time_s=60`；默认 fps=60
- **验收标准**：动主臂，从臂实时跟随无抖动，两个相机画面都流畅 → 可以进入采集

### 3.3 关键参数说明（源码核实）

| 参数                         | 默认           | 说明                                                                                                                                           |
| ---------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dataset.repo_id`        | 必填           | 数据集名 `用户名/数据集名`。**默认自动追加时间戳**（如 `so101_task1_2026-11-17_15-00-00`），想保持原名加 `--dataset.no_stamp=true` |
| `--dataset.single_task`    | `""`         | 任务描述（自然语言，训练时的语言条件）。**注意：本版是 `single_task`，老教程里的 `--dataset.tasks` 已废弃**                          |
| `--dataset.num_episodes`   | 50             | 录多少条 episode。ACT 每任务 ~50 条起步。**配合 `--resume` 时 = 本次新录几条**（不是总条数，已录 12 条补到 50 就填 38）                                           |
| `--dataset.episode_time_s` | 60             | 每条录制时长（秒）                                                                                                                             |
| `--dataset.reset_time_s`   | 60             | 两条之间复位场景的时间（秒）                                                                                                                   |
| `--dataset.fps`            | 30             | 采集频率，**与后续训练 config 必须一致**                                                                                                 |
| `--dataset.push_to_hub`    | **True** | 默认录完自动传 HF Hub！本地练习务必加 `=false`（没配 token 会卡在上传）                                                                      |
| `--dataset.video`          | True           | 图像存 mp4（保持默认）                                                                                                                         |
| `--resume`（**顶层参数**，不在 `--dataset.` 下） | False          | 中断后继续录同一数据集。**必须同时给 `--dataset.root=<数据集目录全路径>`**（本版 resume() 强制显式 root，且 root 指数据集目录本身，不是缓存上级目录；缺 root 报 ValueError，只给上级目录会在元数据找不到时退回 Hub 下载 → 断网报 ConnectError）。此时 num_episodes = 本次新录条数。实例见 `myscript/record_task1_resume.sh` |
| `--play_sounds`            | True           | 语音提示开始/结束                                                                                                                              |

### 3.4 录制中的键盘控制（源码核实：`lerobot_record.py`）

**保存是全自动的，无需任何手动保存操作。** 每条 episode 的生命周期：

```
录制开始（最长 episode_time_s）
   ↓ 动作做完按 →（不按则等满时长自动结束）
语音 "Reset the environment"
   ↓ 10 秒复位期：不录制、从臂仍跟手 ← 用来摆积木复位；按 → 可提前跳过
save_episode() 自动落盘 → 自动开始下一条
```

| 按键                   | 作用                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| **→（右箭头）** | 做完一条按它：立即结束并**保存**本条，进入复位；复位期再按 = 跳过剩余复位直接开录下一条 |
| **←（左箭头）** | 这条砸了**不保存**：清掉缓冲重录同一条（计数不前进）                                                                   |
| **Esc**          | 停止整个会话（已保存的保留），回来加顶层参数 `--resume=true` 续录                                |

唯一会丢数据的操作是按 `←`（主动丢弃）或录制中途拔线。

### 3.5 数据落在哪

```
~/.cache/huggingface/lerobot/zihao/so101_task1*/     ← HF_LEROBOT_HOME 默认位置
├── meta/          info.json、episodes/tasks/stats
├── data/chunk-*/           parquet（state/action/timestamp）
└── videos/observation.images.<相机名>/chunk-*/  每相机一个 mp4（file-000.mp4）
```

环境变量 `HF_LEROBOT_HOME` 可改存储位置；`eval_` 开头的数据集名被保留给评估用，采集时不要用。

## 4. 采集质量检查

1. **录完先回放**（验证数据没毛病再谈训练）：

   ```bash
   uv run lerobot-replay \
       --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=zihao_follower_arm \
       --dataset.repo_id=zihao/so101_task1 \
       --dataset.episode=0
   ```

   从臂应完整复现第 0 条演示动作。
2. **可视化翻看数据集**（不用占机械臂；注意参数是 `--episode-index`）：

   ```bash
   uv run lerobot-dataset-viz --repo-id zihao/so101_task1_20261118_145808 --episode-index 0
   ```

   不跑命令也可以直接看文件：视频在 `~/.cache/huggingface/lerobot/zihao/<数据集>/videos/observation.images.<相机>/chunk-000/file-000.mp4`（任意播放器，注意本机录的是 AV1 编码，需新版 VLC），关节数据在 `data/chunk-000/file-000.parquet`。
3. **健康标准**：录制中终端频率打印稳定在 ~30Hz 无骤降；回放与演示一致；各 episode 长度相近、没有半截的。
4. **批量体检脚本**：`PYTHONPATH= uv run python myscript/check_dataset.py zihao/so101_task1`——逐条帧数/时长/帧间隔断档/各关节活动量/单条全程静止废条检测/视频 ffprobe 完整性，一键全查（2026-11-21 采集验收用的就是它）。

## 5. 常见问题

| 症状                                                          | 处置                                                                                                                                                                                   |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Failed to enable torque ... timed out`（偶发，电机不固定） | **直接重跑**。热插拔 USB 后瞬时扰动常见；已验证总线健康（诊断脚本见下）                                                                                                          |
| 同一个电机反复超时                                            | 接线/电机问题：断电重插该电机及上游链路的 3pin 线；仍不行跑诊断脚本对比                                                                                                                |
| `Failed to open OpenCVCamera(n)`                            | n 撞上元数据节点：偶数=采集。重新 `lerobot-find-cameras opencv` 确认                                                                                                                 |
| 串口 `Permission denied`                                    | `sudo usermod -aG dialout $USER` 后重新登录                                                                                                                                          |
| 采集时频率骤降/掉帧                                           | 关掉多余程序；必要时 `--dataset.num_image_writer_threads_per_camera=8`                                                                                                               |
| 想重新标定                                                    | 最简单：连接时在提示处输入 **`c`** 直接重标（见 §1.3）；或先删标定文件再跑 `lerobot-calibrate`                                                                                       |
| resume 报 `ImportError: 'deepdiff' is required`             | `uv sync --locked --extra deepdiff-dep` 一次性补装（resume 兼容性检查专用，首录不需要）                                                                                              |

本机自测脚本（都在仓库根 `myscript/` 下，运行方式 `cd /mnt/nvme01/workplace/lerobot && PYTHONPATH= uv run python myscript/<脚本> [参数]`；详细说明见 [`../myscript/README.md`](../myscript/README.md)）：

| 脚本                      | 作用                                                     | 备注                                     |
| ------------------------- | -------------------------------------------------------- | ---------------------------------------- |
| `diag_follower.py`        | 总线诊断：通信稳定性/电压/温度/逐电机力矩                | 从臂短暂锁紧，3 秒缓冲                   |
| `verify_motor_order.py <串口>` | 电机 ID 顺序自测（逐关节手拧判定 ✓/✗）              | 无力矩；两臂各测一次                     |
| `elbow_sync_test.py`      | 主从一致性分步自测（肘部重点，分 5 步引导）              | 从臂上力矩跟随；数据存 `myscript/arm_sync_*.csv` |
| `compare_arms.py`         | 20 秒主从跟随对比 + 自动统计偏差                         | 从臂上力矩                               |
| `identify_arms.py`        | 串口身份识别（拧主臂底座看哪个口动）                     | 无力矩；插拔后确认 ttyACM 对应           |
| `probe_ports.py`          | 两个串口的电机应答探测                                   | 无力矩                                   |
| `voltage_check.py`        | 两臂电压/温度读数                                        | 无力矩（电压单位 0.1V）                  |
| `release_check.py`        | 释放从臂力矩 + 两臂姿势快照                              | 脚本异常中断后先跑这个                   |
| `check_dataset.py <repo_id>` | 数据集批量体检：断档/半截/静止废条/视频完整性         | 无硬件；录完批次跑一次                   |
| `calibrate_single_motor.py <臂> <电机>` | 单电机零点+行程重标（其余 5 个不动，自动 .bak） | 无力矩                                   |

## 6. 一页速查

```bash
# 找相机 → 记住偶数号 index
uv run lerobot-find-cameras opencv

# 校准（新臂必做；漂移重标：连接提示处输入 c 即可，见 §1.3）
uv run lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=zihao_follower_arm
uv run lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=zihao_leader_arm

# 电机 ID 设置（全新电机一次性）
uv run lerobot-setup-motors --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=zihao_leader_arm

# 遥操作验收（双相机）
uv run lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=zihao_follower_arm \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}, third_person: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=zihao_leader_arm --display_data=true

# 示教采集 = 上面的 robot/teleop/cameras 原封不动 + dataset 参数
#   → 键盘：→ 下一条 | ← 重录 | Esc 停止
#   → 本地练习记得 --dataset.push_to_hub=false
#   → 续录用 myscript/record_task1_resume.sh（resume 参数坑见 §3.3）

# 回放验证 → lerobot-replay；翻数据 → lerobot-dataset-viz（--episode-index）
```
