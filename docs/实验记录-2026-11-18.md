## 二、问题定位过程

### 2.1 重标定与标定文件复核

用连接提示处的 `c` 键重标两臂（不需要删标定文件）后复核 JSON（`~/.cache/huggingface/lerobot/calibration/`）：

| 关节 | 从臂 homing / range | 主臂 homing / range | 复核结论 |
|---|---|---|---|
| shoulder_pan | 1983 / [760, 3014] | -1304 / [505, 3123] | ✅ 正常 |
| shoulder_lift | 831 / **[2, 4094]** | 1201 / **[0, 4091]** | ⚠️ 全量程（见 2.3 结论） |
| elbow_flex | -819 / [132, 2201] | -714 / **[3, 4093]** | 从臂修复；主臂全量程（同上） |
| wrist_flex | -1733 / [468, 2618] | -1992 / [700, 3028] | ✅ 正常 |
| wrist_roll | -146 / [0, 4095] | -1195 / [0, 4095] | 整圈关节，官方流程不扫行程 |
| gripper | 1217 / [2033, 3146] | -1597 / [1704, 2868] | ✅ 正常 |

关键事实：**同一操作者两次仔细重标，shoulder_lift 两臂与主臂 elbow 仍稳定复现"全量程"**，而其余关节标定健康——排除"操作失误"假说。

### 2.2 主从一致性实测（关键实验）

写 `myscript/compare_arms.py`：加载两臂标定，走与 `lerobot-teleoperate` 完全相同的归一化路径（主臂读数直接作为从臂 Goal_Position），20 秒镜像并排记录两臂各关节角度。

结果：**静止/慢动状态下所有关节主从偏差仅 0.1°~2.5°**；快速甩动时的 60°+ 大偏差均为瞬时跟随滞后（追赶过程可见），非映射错误。补充抓拍：两臂都摆到肘弯约 90° 姿势时，主臂 86.5° / 从臂 90.4°，肩部 -36.5°/-37.3°——远离中位的大角度下仍吻合。

### 2.3 结论修正（推翻昨天的初判）

- **"全量程 range"不是标定损坏**：SO-101 的 shoulder_lift / elbow 关节无限位挡块，主臂这两个关节物理上可旋转接近整圈（≈359°），扫行程记录到 [0,4095] 是**真实机械行程**；
- range 只用于行程裁剪保护，角度换算只依赖 homing_offset（中位半圈归零）——全量程不影响映射正确性；
- 昨天"姿态不对"的实际来源：动态跟随滞后 + 肉眼感知误差 + 当时的接线瞬态问题，标定本身可用；
- 教训：**中位对齐不能证明映射正确（两臂 0° 都由标定姿势定义），验证必须在远离中位的角度测**。

## 四、产生的脚本（`myscript/`，均有中文提示，统一 `PYTHONPATH= uv run python myscript/<脚本>` 运行）

| 脚本 | 作用 | 上力矩？ |
|---|---|---|
| `probe_ports.py` | 双串口电机应答探测 | ❌ |
| `identify_arms.py` | 串口身份识别（拧主臂底座看哪个口动） | ❌ |
| `voltage_check.py` | 两臂电压/温度读数 | ❌ |
| `verify_motor_order.py <串口>` | 电机 ID 顺序自测：逐关节手拧，自动判 ✓/✗（握手段：ID 缺号直接握手失败暴露） | ❌ |
| `compare_arms.py` | 20 秒主从镜像对比 + 各关节偏差统计（今日定位问题的主力） | ✅ 从臂 |
| `elbow_sync_test.py` | 主从一致性分步自测（5 步引导，数据存 `arm_sync_*.csv`） | ✅ 从臂 |
| `release_check.py` | 释放从臂力矩 + 两臂姿势快照（脚本中断后善后） | ❌（只释放） |
| `diag_follower.py` | 从臂总线全面诊断：30 轮通信/电压/温度/逐电机+全体力矩/带载电压 | ✅ 从臂 |
| `calibrate_single_motor.py <臂> <电机>` | 单电机零点+行程重标（源码核实 `set_half_turn_homings`/`record_ranges_of_motion` 支持子集；其余 5 电机不动，自动备份 .bak） | ❌ |

配套 `myscript/README.md`：通用规则（`PYTHONPATH=` 前缀防 ROS2 环境污染）、按场景工作流、串口对调应对（`/dev/serial/by-id/` 稳定路径，从臂序列号 `5CBC431912`、主臂 `5CBC430736`）、安全红线。

## 五、知识沉淀（写入手册的修正与新增）

- 重标定不用删文件：连接提示处输入 **`c`** 即可重跑标定；
- 串口按插入顺序分配、可对调；板上 USB 序列号不变，用 by-id 稳定路径或 `identify_arms.py` 确认；
- `lerobot-dataset-viz` 参数是 **`--episode-index`**（不是 `--episodes`）；
- 数据集实际布局：`videos/observation.images.<相机>/chunk-000/file-000.mp4`；数据集名 = 目录名（`info.json` 不存 repo_id，改名安全）；
- 12V 误插主臂无害，但主臂永不上力矩；从臂 12V 必须在位。

## 六、遗留与风险

- 空壳数据集目录（0 episode）每次启动录制即生成，注意清理；
- 偶发 motor timeout 属瞬态（重跑即愈）；反复超时才查 3pin 链路与 12V 供电；
- ACT 训练前需解决 GPU：本机装 CUDA 版 PyTorch（若有 N 卡）或换机器/云 GPU。
